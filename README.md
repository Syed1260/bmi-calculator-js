# BMI Calculator    A simple Body Mass Index (BMI) calculator built with **HTML, CSS, and JavaScript**.    ## Features   - User inputs weight (kg) and height (cm/m).   - Calculates BMI instantly.   - Displays BMI category (Underweight, Normal, Overweight, Obese).   - Clean and responsive UI.    ## Technologies Used   - HTML   - CSS   - JavaScript
